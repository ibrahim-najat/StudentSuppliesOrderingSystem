# Student Supplies Ordering System

## Project Description
The Student Supplies Ordering System is a simple web application for a campus supplies shop. It allows students to select school supplies, manage their shopping cart, calculate their order total, pay for their purchases, and receive a digital receipt.

## Features
- Display six school supplies with their prices.
- Add products to the shopping cart.
- Increase and decrease product quantities.
- Remove individual products from the cart.
- Automatically calculate subtotals and the order total.
- Validate cash payments and reject insufficient payments.
- Calculate the customer's change.
- Generate a digital receipt with a transaction reference.
- Start a new transaction by clearing the previous purchase.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add products to the cart and test the payment process.
