# AI Usage Documentation
## Student Supplies Ordering System

### AI Interaction 1 — HTML Structure

**Purpose:** To generate the HTML structure for the Student Supplies Ordering System.

**Prompt Used:** I asked an AI assistant to create the complete `index.html` file for my Student Supplies Ordering System, including the product list, shopping cart, order summary, payment section, and receipt section.

**AI Response Summary:** The AI provided HTML code containing the main sections of the application, product buttons, cart elements, payment form, and receipt area.

**Evaluation:** I reviewed the generated HTML and checked whether the required sections and element IDs were present and compatible with the JavaScript.

**Modifications and Testing:** I saved the HTML file, ran the application in my browser, and tested the interface and its interactive features.

### AI Interaction 2 — CSS Styling

**Purpose:** To style the application and make the interface responsive.

**Prompt Used:** I asked an AI assistant to create the complete `style.css` file for my existing Student Supplies Ordering System without changing the HTML or JavaScript.

**AI Response Summary:** The AI provided CSS for the page layout, product cards, shopping cart, payment form, receipt, buttons, and responsive screen sizes.

**Evaluation:** I checked the appearance of the interface and verified that the styling worked with my existing HTML.

**Modifications and Testing:** I saved the CSS file and checked the interface in my browser.

### AI Interaction 3 — JavaScript Functionality

**Purpose:** To implement the shopping cart, payment validation, calculations, and receipt generation.

**Prompt Used:** I asked an AI assistant to create the complete `script.js` file for my existing application, using the six required products and their prices.

**AI Response Summary:** The AI provided JavaScript for adding products, changing quantities, removing items, calculating totals, validating cash payments, calculating change, generating receipts, and starting new transactions.

**Evaluation:** I tested the application using the required scenarios, including cart operations, payment validation, successful payments, change calculations, and new transactions.

**Modifications and Testing:** I reviewed the code, saved it, and tested the application in the browser. I confirmed that the main buttons and transaction functions worked as expected.

### Conclusion

AI assisted me in developing the HTML structure, CSS styling, and JavaScript functionality. I reviewed the generated code and tested the application to check that it met the project requirements. Git and GitHub were used to track and upload the project changes.
